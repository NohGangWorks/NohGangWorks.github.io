허락 없이 앱이나 기본 제공 자산을 별도 상품으로 재판매·재배포하거나, 라이선스·보안 장치를 우회하거나, 서비스를 방해하거나, 타인의 권리를 침해하는 데 사용해서는 안 됩니다. 강행법규 또는 제3자 오픈소스 라이선스가 허용하는 행위는 제한하지 않습니다.

4. 선택적 클라우드 저장

사용자가 Google Drive 또는 Microsoft OneDrive를 연결하면 앱 모드·Program Options 설정, 사용자 파생 템플릿과 연결된 썸네일, 기본 제공 템플릿의 사용 횟수·마지막 사용 시각을 개인 클라우드 계정과 동기화합니다. 세션·현재 작업 상태와 별도의 사진·영상·폰트 등 원본 콘텐츠 파일은 제외합니다. 클라우드 연결은 Normal·Expert 모드에서 제공하며 Easy 모드에서는 동기화를 실행하지 않습니다. 동기화 중지·모드 변경만으로 클라우드 파일이 삭제되지는 않습니다.

Google Drive는 앱이 만든 NGST/expressit 폴더를 사용하고 이전 숨김 앱 데이터를 읽어 이전할 수 있습니다. OneDrive는 Microsoft Graph API와 앱 폴더 권한을 이용해 사용자의 OneDrive 앱 전용 폴더에 저장합니다. 연결은 제공자의 인증·동의 절차를 거칩니다. 제공자의 저장 한도와 Google 이용약관 또는 Microsoft 서비스 계약 등 해당 서비스의 조건이 적용됩니다. 여러 제공자를 연결하면 기기에 동기화된 같은 데이터가 각각의 연결된 계정으로 전송될 수 있습니다.

설정·템플릿의 충돌은 수정 시각 등 동기화 규칙에 따라 처리하며 사용자 템플릿의 삭제도 반영될 수 있습니다. 기본 템플릿 사용 기록은 설치별 카운터를 합칩니다. 클라우드에서 받은 설정·템플릿은 앱을 다시 시작할 때 적용될 수 있습니다. 모든 수정 이력을 보관하거나 외부 콘텐츠 원본까지 복구하는 백업 서비스는 아닙니다.

파일은 읽을 수 있는 형식이며 앱 자체의 종단간 암호화는 제공하지 않습니다. 다른 앱에서 동기화 파일을 편집·이름 변경·삭제하면 사용할 수 없게 되거나 동기화 중 교체될 수 있습니다. 중요한 콘텐츠는 별도 사본을 보관하세요. 제공자의 용량·API 제한, 네트워크와 계정 권한, 기기 시계의 정확도에 따라 지연·실패·재연결이 발생할 수 있습니다.

연결 해제는 해당 기기의 동기화를 중단하고 저장된 연결 인증정보를 제거하며 로컬 콘텐츠·기존 클라우드 파일·다른 기기의 연결을 자동 삭제하지 않습니다. 삭제하려면 모든 기기에서 연결을 해제한 뒤 Google Drive의 앱 폴더와 이전 숨김 앱 데이터, 또는 OneDrive의 앱 전용 폴더에 저장된 파일을 제공자의 관리 기능으로 지우고 필요한 경우 휴지통을 비우세요. 계정에서 앱 접근 권한도 철회할 수 있습니다. 연결이 남은 기기는 데이터를 다시 업로드할 수 있습니다. 상세 처리·보관·삭제 방법은 개인정보처리방침에 따릅니다.
