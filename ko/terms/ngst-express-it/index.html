허락 없이 앱이나 기본 제공 자산을 별도 상품으로 재판매·재배포하거나, 라이선스·보안 장치를 우회하거나, 서비스를 방해하거나, 타인의 권리를 침해하는 데 사용해서는 안 됩니다. 강행법규 또는 제3자 오픈소스 라이선스가 허용하는 행위는 제한하지 않습니다.

4. 선택적 클라우드 저장

사용자가 제공 중인 클라우드 서비스를 연결하면 Program Options 설정과 사용자가 만든 파생 템플릿을 개인 클라우드 계정과 동기화합니다. 세션 데이터는 제외합니다. 클라우드 연결은 Normal·Expert 모드에서 제공하며 Easy 모드에서는 동기화를 실행하지 않습니다. 동기화가 중지되거나 모드가 바뀌어도 클라우드 파일은 남습니다.

파일은 읽을 수 있는 설정·템플릿 형식을 사용합니다. 앱 밖에서 동기화 파일을 수정·이름 변경·삭제하면 파일을 읽지 못하거나 동기화 중 다른 버전으로 대체될 수 있습니다. 중요한 콘텐츠는 변경 전에 별도로 복사해 두세요. 제공자의 용량 제한, 네트워크 상태, 계정 권한과 기기 시계의 정확성이 동기화에 영향을 줄 수 있으며, 각 제공자의 약관과 개인정보처리방침도 적용됩니다.
