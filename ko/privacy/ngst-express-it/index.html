1. 기기 내 정보 처리

앱은 설정, 템플릿, 작업 파일과 사용자가 선택한 콘텐츠를 기기에서 처리합니다. 회사는 앱 기능을 통해 이를 전송받지 않습니다. 로컬 파일은 사용자가 운영체제에서 직접 관리합니다.

2. 외부 서비스와 이메일 문의

앱은 작업 콘텐츠, 식별자 또는 이용 분석정보를 회사 서버로 업로드하지 않습니다. 사용자가 앱 스토어, 운영체제 기능, 외부 앱 또는 공유 기능을 선택하면 해당 제공자의 정책이 적용됩니다.

이메일 문의 시 이메일 주소, 제공한 이름, 내용과 첨부파일을 답변을 위해 처리합니다. 일반 문의는 최종 답변 후 30일 이내 삭제하며, 전자상거래법상 소비자 불만·분쟁 기록은 3년간 보관할 수 있습니다. Cloudflare의 메일 전달과 국외 처리 사항은 웹사이트 개인정보처리방침에 안내합니다.

3. 제공·추적·자동화된 결정

회사는 앱 개인정보를 판매하거나 광고 목적으로 공유하지 않으며, 분석 SDK·광고 식별자·추적 SDK를 사용하지 않습니다. 법적 효과 또는 이와 유사한 중대한 영향을 미치는 자동화된 결정도 하지 않습니다.

4. 파기와 권리 행사

회사가 보유한 문의 정보는 보유기간이 끝나면 삭제합니다. 정보주체와 법정대리인은 열람, 정정·삭제, 처리정지 또는 동의 철회를 아래 연락처로 요청할 수 있습니다. 로컬 콘텐츠는 사용자가 기기에서 직접 관리합니다.

5. 아동·보안·향후 기능

이 앱은 아동을 대상으로 하지 않으며 만 14세 미만 아동과 미국의 만 13세 미만 아동의 개인정보를 고의로 수집하지 않습니다. 필요한 보호자 동의 없이 접수된 사실을 알게 되면 삭제합니다.

기기 중심 설계로 전송을 최소화합니다. 향후 계정, 동기화, 분석 또는 광고 기능이 추가되면 본 방침과 필요한 고지를 갱신합니다.
