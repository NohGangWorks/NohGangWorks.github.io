1. 기기 내 정보 처리

앱은 설정, 템플릿, 작업 파일과 사용자가 선택한 콘텐츠를 기기에서 처리합니다. 세션 데이터는 기기에 남으며 클라우드 동기화에서 제외합니다. 로컬 사용 횟수와 화면 상태는 회사의 이용 분석 서비스로 전송하지 않습니다. 내보내기, 공유 대상 및 사용하는 기기 간 연결 기능은 사용자가 선택합니다.

2. 선택적 Google Drive 동기화

선택과 목적. Normal·Expert 모드에서 Google 공식 인증 화면을 통해 계정을 연결하면 기기 간에 앱 설정과 사용자가 만든 파생 템플릿을 동기화할 수 있습니다. 앱은 Google 비밀번호를 받지 않으며 노강웍스 계정을 요구하지 않습니다. Easy 모드에서는 클라우드 동기화를 실행하지 않습니다.

접근·전송 항목. Program Options 파일과 사용자 템플릿 파일을 업로드·다운로드하며, 그 파일에 포함된 텍스트, 설정, 파일 참조 및 기타 데이터도 함께 처리합니다. 템플릿에는 사용자가 입력한 개인정보가 포함될 수 있습니다. 변경 확인을 위해 파일 식별자·이름·편집 시각·해시·삭제 표시를 처리하고, 앱 사용 용량 표시를 위해 계정의 저장 용량 정보를 조회합니다. 세션 데이터는 포함하지 않으며, 기기의 모든 파일을 업로드하거나 Drive 전체 파일에 대한 접근 권한을 요청하지 않습니다.

권한과 저장 위치. drive.file 권한으로 앱이 만들었거나 앱에 사용을 허용한 파일에 접근합니다. 새 클라우드 데이터는 앱이 만든 NGST/expressit 폴더에 저장합니다. drive.appdata 권한은 이전의 숨김 앱 데이터 백업을 읽고 이전하는 데 사용하며, 새 파일은 표시되는 폴더에 저장합니다. 이전 후에도 숨김 사본이 남을 수 있습니다. Google은 사용자의 계정과 개인정보처리방침에 따라 클라우드 데이터를 처리·보관하며, 사용자의 국가 밖 서버에서 처리할 수 있습니다.

보관과 보호. 설정·템플릿은 읽을 수 있는 INI·JSON 형식으로 저장하며 앱이 클라우드 파일에 별도의 종단간 암호화를 적용하지는 않습니다. Google과의 통신에는 HTTPS를 사용합니다. 접근 토큰과 발급되는 갱신 토큰은 플랫폼이 보호하는 기기 저장소에 따로 보관하며, 동기화하는 설정·템플릿에 넣지 않습니다. 변경사항을 비교·적용하기 위한 로컬 동기화 기록과 다운로드 대기 데이터도 보관하며 동기화 파일의 사본을 포함할 수 있습니다. 마지막 동기화 시각·전송량·사용 용량은 앱에서 표시하며 회사 분석 서버로 전송하지 않습니다.

이용과 공유. Google 사용자 데이터는 사용자가 요청한 동기화와 저장 현황 제공에만 사용합니다. 판매, 광고, 신용 판단 또는 범용 AI 모델 학습에 사용하지 않습니다. 회사 직원이 사용자의 클라우드 파일을 상시 열람하지 않습니다. 사용자가 지원 문의에 자발적으로 첨부한 콘텐츠는 문의 정보로 처리합니다. 사용자가 다른 지원 제공자도 별도로 연결하면 동기화된 앱 파일이 해당 계정에도 업로드될 수 있습니다. 목록에 표시만 되고 연결되지 않은 제공자에는 이 파일을 전송하지 않습니다.

NGST Express It이 Google API에서 받은 정보를 이용·이전하는 방식은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. 새 제공자나 중요한 처리 방식 변경은 활성화 전에 설명하고 필요한 동의를 받습니다.

3. 외부 서비스와 이메일 문의

앱은 작업 콘텐츠, 식별자 또는 이용 분석정보를 회사 서버로 업로드하지 않습니다. 사용자가 앱 스토어, 운영체제 기능, 외부 앱 또는 공유 기능을 선택하면 해당 제공자의 정책이 적용됩니다.

이메일 문의 시 이메일 주소, 제공한 이름, 내용과 첨부파일을 답변을 위해 처리합니다. 일반 문의는 최종 답변 후 30일 이내 삭제하며, 전자상거래법상 소비자 불만·분쟁 기록은 3년간 보관할 수 있습니다. Cloudflare의 메일 전달과 국외 처리 사항은 웹사이트 개인정보처리방침에 안내합니다.

5. 파기와 권리 행사

앱에서 연결을 해제하거나 Google 계정의 연결 관리에서 접근 권한을 철회할 수 있습니다. 연결 해제는 해당 기기의 저장된 연결 인증정보를 제거하며, 로컬 콘텐츠·기존 클라우드 파일·다른 기기의 인증정보를 삭제하지 않습니다. 모드 변경도 클라우드 데이터를 삭제하지 않습니다. 로컬 동기화 기록과 다운로드 대기 데이터는 앱 데이터를 제거할 때까지 남을 수 있습니다.

클라우드 사본을 삭제하려면 모든 기기에서 연결을 해제한 뒤 앱이 만든 NGST/expressit 파일을 삭제하고 필요한 경우 제공자의 휴지통도 비우세요. 이전에 숨김 앱 데이터 백업을 사용했다면 Google Drive의 앱 관리 기능으로 해당 데이터도 제거하세요. 연결된 기기나 남아 있는 이전 백업 때문에 데이터가 복원될 수 있습니다. 제공자의 백업 보관과 삭제에는 제공자의 정책이 적용됩니다. 로컬 사본은 동기화 캐시를 포함하여 앱 또는 운영체제의 파일·앱 데이터 관리 기능으로 제거할 수 있으며, 보관할 내용이 있다면 먼저 내보내세요.

회사가 보유한 문의 정보는 보유기간이 끝나면 삭제합니다. 정보주체와 법정대리인은 아래 연락처로 열람, 정정·삭제, 처리정지, 동의 철회 등 관계 법령상 권리를 요청할 수 있습니다. 기기나 개인 클라우드에만 보관된 파일은 회사가 직접 삭제할 수 없으므로 위 관리 기능을 이용해야 합니다.
